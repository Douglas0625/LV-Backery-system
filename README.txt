# LV Bakery System

## Requisitos

* Java 17
* PostgreSQL 15
* Maven

---

## Configuración de Base de Datos

1. Crear base de datos:

```sql
CREATE DATABASE lv_bakery;
```

2. Ejecutar:

```text
database/lv_bakery.sql
```
